Ejercicio 3: comando en evento

El código de JavaScript se asocia a un elemento HTML (un botón) y se ejecuta cuando ocurre un evento (el click). Se escribe como valor del atributo de evento onClick.

Al hacer click en el segundo botón, document.write() reemplaza todo el contenido de la página: el flujo de escritura ya está cerrado y la función pisa el documento original.
