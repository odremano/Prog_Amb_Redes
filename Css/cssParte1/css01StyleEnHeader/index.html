Declaraciones en bloque definidas entre etiquetas style

La etiqueta h1 ocupa todo el ancho de su contenedor padre por default (lleva un display de tipo bloque), por eso el fondo aquamarine se extiende de extremo a extremo aunque el texto esté centrado.

Este párrafo toma el estilo definido para toda etiqueta p del documento: texto azul, en cursiva y con un borde superior e inferior finos y sólidos. Este bloque de declaraciones fue escrito dentro de la etiqueta <style></style> ubicada en el encabezado (head) del documento, reemplazando el uso del atributo style="" dentro de cada etiqueta individual.
