Selectores de clase

A partir de esta página no usaremos más el atributo style en ninguna etiqueta. Todo el estilo aplicado en el documento será definido dentro de una etiqueta style como "clase", anidada en la etiqueta head del documento.

Este párrafo usa la clase claseResaltado: negrita y fondo amarillo.

Este párrafo usa la clase claseAcotacion: texto en cursiva con borde fino.

Este párrafo usa la clase claseAyuda: texto naranja dentro de una caja con borde.

Este es un párrafo de contenido común, sin estilo particular más allá del default.

Este párrafo usa el selector de id #idUnico. No se trata de un selector de clase sino de un selector de elemento único dentro del documento (atributo id="idUnico").

Todas las imágenes con class="imagenAl50" en esta página se encuentran limitadas al 50% del ancho del contenedor más allá de su tamaño real en píxeles.
