Fondo fijo (background-attachment: fixed)

El padding es importante para que el texto no quede pegado al borde. No hay que olvidar usar box-sizing:border-box para que la dimensión de la caja sea exactamente la definida en el width, incluyendo el padding y el borde hacia adentro.

Con background-attachment:fixed, la imagen de fondo queda fija respecto al scroll del contenido: si el texto de este div tiene más contenido del que entra en los 300px de alto, aparecerá una barra de scroll (overflow-y:auto) y al desplazarte, el fondo no se moverá con el texto.
