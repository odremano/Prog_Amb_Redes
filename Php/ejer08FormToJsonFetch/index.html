Form to json con API fetch

Ejercicio sin estilos a propósito. Un mismo formulario se puede enviar de dos maneras: con el botón tradicional, la respuesta (solo un JSON) reemplaza al documento; con el botón AJAX, el requerimiento es asincrónico y la respuesta llega a un alert sin recargar la página. El servidor demora 3 segundos a propósito.
