Ajax con API fetch

Es el mismo ejercicio de encriptación del anterior, pero ahora el requerimiento HTTP es asincrónico: el formulario no se envía de la forma tradicional, sino que el botón dispara un fetch() y el documento nunca se recarga. El servidor demora 3 segundos a propósito (sleep) para poder ver el estado del requerimiento mientras la promesa está pendiente. Cuando la promesa se cumple, la respuesta se ubica en el panel de resultado.
